# Al Majlis Vector app icon

Al Majlis Studio icon, made for the Ministry with Higgsfield (Ideogram Vector), 2026-11-12. Owner approved 2026-11-12.

The Al Majlis Studio family look: an Al Majlis blue rounded tile (`#2a78f9`, corner radius 20 % of
the tile, transparent corners) with a white line glyph: Bezier curves with anchor points.

## Files

| File | What |
|---|---|
| `vectorcraft.svg`, `vectorcraft-small.svg`, `hicolor/scalable/apps/ai.storyteller.vectorcraft.svg` | the vector (the approved trace, cropped and clipped to the rounded tile) |
| `hicolor/<n>x<n>/apps/ai.storyteller.vectorcraft.png` | full-bleed renders, 16-512 px; the 128 px one is the in-app mark and About icon, the 256 px one the window icon |
| `vectorcraft-1024.png`, `vectorcraft-macos-512.png`, `vectorcraft.icns`, `vectorcraft.ico` | the same tile at the placement each file had before (Apple grid on macOS, full bleed on Windows) |

File names and the app id `ai.storyteller.vectorcraft` are unchanged (code and packaging depend on them).
